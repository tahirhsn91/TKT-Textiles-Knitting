## 🎬 What is This App About?

Imagine you have a **big factory** that makes pretty **fabrics and clothes**! 👕👔

Our app helps everyone in the factory do their jobs easily:
- 👷 Workers make the clothes
- 👨‍💼 Managers check if everything is working well
- 👨‍💻 The Boss (Admin) makes sure everyone is happy!

## 🎯 Simple Summary (The Whole Flow!)

```
EVERYONE'S DAY AT THE FACTORY:

1️⃣  Morning: Everyone Logs In
   Hassan → Control Room (See everything!)
   Khurram → Check what's happening
   Iftikhar → Start working on machines

2️⃣  Throughout Day:
   Iftikhar → Makes clothes 👕
            → Records what he made
            → Reports broken machines
   
   Khurram → Checks production
           → Approves money spending
           → Pays workers
   
   Hassan → Sees everything
          → Makes big decisions
          → Manages all workers

3️⃣  End of Day:
   Iftikhar → Logs out (goes home! 🏠)
   Khurram → Reviews the day
   Hassan → Checks reports 📊

4️⃣  Next Day: Repeat! 🔄

MAGIC PART: 
Hassan can see what Khurram can see 👀
Khurram can see what Iftikhar can see 👀
But Iftikhar can't see what Khurram and Hassan see 🚫
```

```
USER TYPES SOMETHING
        ↓

        ↓

        ↓
```
