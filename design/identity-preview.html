Visual identity

Mass Balance

The whole product exists to make a kilogram traceable from cone to roll. So the interface is built as an instrument rather than a dashboard: numbers are the subject, colour is rationed, and every figure sits on a monospaced grid where a transposed digit changes the shape of the column.

The shell

Sidebar, reading panel, tables

The sidebar is a bezel, not a panel — dark ground, so the light work area reads unmistakably as the work area. The 3 px orange band on the active item is the selvedge: the finished, non-fraying edge of a knitted piece. It is the only place the brand colour appears in the chrome.

Palette

Seven values, one of them rationed

Signal is TKT's brand colour and the loudest thing available, so it is spent in exactly three places: the selvedge, the focus ring, and one primary action per screen. Charts run on vat indigo instead, which keeps the orange meaningful when it does appear.

Two voices

System stacks only — no webfont CDN

Prose gets the system UI stack with tight tracking. Every quantity gets the mono stack with tabular, slashed-zero figures. That second voice is the identity, and it does real work: columns of kilograms align on the decimal and a mistyped digit is visible at a glance.
