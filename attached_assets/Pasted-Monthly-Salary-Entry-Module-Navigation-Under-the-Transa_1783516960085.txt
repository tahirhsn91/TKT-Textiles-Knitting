Monthly Salary Entry Module
Navigation

Under the Transactions menu, on clicking Monthly Salary Entry, display a screen containing the following action buttons:

Add New Salary
Export CSV

In addition, display a list/grid of previously saved salary records showing at least the Month, Year, Department(s),  Created Date, and Status. Each record shall provide the following action buttons:

Edit
Delete
Add New Salary

When the user clicks Add New Salary, open the Monthly Salary Entry screen consisting of a Header section and a Detail section.

Header Section

Provide the following input fields:

Field	Type	Description
Month	Dropdown/Month Picker	Default value shall be the previous month (Current Month - 1).
Year	Dropdown	Default value shall be the current year corresponding to the selected month.
Department	Multi-select Dropdown	Allow selection of one or more departments.
Detail Section

After the user selects the department(s), display all active employees/operators belonging to the selected department(s).

Auto-populated Fields (Retrieved from Operators Master)

The following values shall be automatically retrieved from the Operators Master table where Active = True:

Department
Employee Name
Basic Salary
Overtime Rate per Hour (OT_Rate_Hr)
Attendance Allowance (Att_Allowance)
Other Allowance (Oth_Allowance)
User Input Fields

The user shall be able to enter or modify the following fields for each employee:

Total Present Days
Total Absent Days
Total Holidays
Total Attendance
Total Salary = ((Basic Salary/Total Days of the selected month)*Total Attendance) editable
Overtime Total Hours
Overtime Amount = (Overtime Total Hours × OT_Rate_Hr) edit able
Advance Deduction
Loan Deduction
Other Deduction
Payable Salary = ((Total Salary+Overtime Amount)-(Advance Deduction+Loan Deduction+Other Deduction))
Save

On clicking Save, the system shall:

Validate all mandatory fields.
Save the salary record along with all employee salary details.
Prevent duplicate salary entries for the same Month, Year, Department, and Employee, unless the existing record is being edited.
Display a confirmation message indicating that the salary entry has been saved successfully.
Edit

Once a salary entry has been saved, the user shall be able to edit it by clicking the Edit button

The system shall:

Load the selected salary record into the Salary Entry screen.
Allow modification of both Header information (where applicable) and Detail information.
Recalculate all dependent values, including Overtime Amount and Payable Salary, whenever related fields are modified.
Save the updated record while maintaining an audit trail of the last modified date and user (if audit functionality is available).

Post/Un-Post 

Provide a "Post" and "Un-Post" Tag (Yes/No)

"Post"/"Un-Post" button - Provide Post/Un-Post button, pressing "Post" button should mark record as Posted which could not be edited or deleted with a Posted message while "Un-Post" button should unmark all records as unposted that would ultimate  provide edit facility

Delete

The user shall be able to delete a saved salary entry by clicking the Delete button.

The system shall:

Display a confirmation message before deleting the record.
Delete both the salary header and all associated employee salary detail records.
Prevent deletion if the salary has already been approved, processed, or used in payroll (if such workflow exists).
Display a success message after successful deletion.
Data Source

Employee records shall be retrieved from the Operators Master table using the following criteria:

Active = True
Department is one of the departments selected by the user.

Only matching active employees shall be displayed in the salary entry grid.

Export CSV

When the user clicks Export CSV, the system shall export the Monthly Salary Entry data for the selected Month, Year, and Department(s) into a CSV file.
