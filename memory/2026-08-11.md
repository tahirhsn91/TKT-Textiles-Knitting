## Key operational notes (learned this session)
- **Docker builds MUST run in background** with `background:true, timeout:600` then poll (per AGENTS.md). Containers rebuilt via `docker compose build --no-cache` then `up -d`. Rebinding code→containers requires rebuild (running containers hold old image).
- **Backend CRUD pattern** (mirror daily-deliveries): schema file in `backend/src/db/schema/*.ts` → register in `schema/index.ts` → route file in `backend/src/routes/*.ts` → register in `routes/index.ts`. Migrations handwritten as `database/migrations/NNNN_name.sql` and applied directly to live Postgres (repo convention — some migrations lack meta snapshots). Frontend hooks are handwritten in `frontend/src/hooks/*.ts` using `customFetch`.
- **Live DB access**: Postgres reachable for smoke-testing generated SQL / seeding / cleaning test data. Transaction type "Fabric Production" identified by `code === "Fabric_Production"` (lookup pattern from `salary-entries.ts`).
